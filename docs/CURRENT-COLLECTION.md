# Current Sceneology public collection

**Recorded:** October 26, 2026. Source of truth: [catalog/showcase.json](../catalog/showcase.json), cross-checked against [catalog/library.json](../catalog/library.json).

The live [Sceneology exhibition](https://sguzman.github.io/sceneology/) contains **24 selected works**: 7 environments, 16 models/objects, and 1 character. These are source-backed works selected based on documented earlier approval, not a claim that every original renderer and static preview are pixel-identical. Some works use reconstructed presentation thumbnails, and their individual limitations are in the technical catalog.

## Separate from the gallery

The wider repository contains archived rendering experiments, rejected visual approaches, four accepted but **source-only** room compositions whose visual renderers have not yet been reconstructed, and other research. Those are not automatically featured. The public model index also exposes multiple technical variants, but a source file or working viewer alone does not mean the owner liked its result.

The earlier [migration roadmap](ROADMAP.md) is **100/100 for its bounded acceptance contract**, not for total recovery of all historical artwork. New visual admissions require exactly reviewed source bytes, a non-misleading thumbnail, tested viewer and clear owner preference evidence.
