# 🧍 Character variant and acceptance boundaries

Sceneology preserves a character's technical history without interpreting **partial improvement** as an approved piece of artwork. This selection register summarizes already-public project evaluations, not private commentary or a new artistic verdict.

| Character revision | Evidence-backed status | Exhibition decision |
| --- | --- | --- |

| Cozy Reader Girl v3/v4 | Human-rejected reference-fit attempts | Excluded from curated exhibition |
| Princess Idle 001 | Source alpha-integrity failure, production admission blocked | Excluded until a replacement passes QA |

See the [machine-readable selection ledger](../catalog/character-variant-triage.json) for source paths, evaluation references and scoped dispositions.

Motion and static appearance are different verdicts. A character whose static form is approved may still have failed or only functionally accepted motion. Do not label a functional animation test an artistic approval, nor promote a rejected body/face merely because individual components or automated tests passed.

Historical negative results remain valid technical research. Neither rejection nor a source file's presence authorizes copying unpublished reference assets or comments into Sceneology. Source ownership, rights, dependencies, and current output must be reviewed separately for each later candidate.

## Functional motion v0.2 technical recovery

The source-reviewed [Quest Girl v7 motion lab](https://sguzman.github.io/sceneology/characters/quest-girl-motion.html) now samples four original-valued rigid-pivot clips: soft idle, look around, small wave and step in place. It uses the 44-part static character, retains the original source clip durations, frequencies, amplitudes and keyframe values, and preserves the explicit boundary of **functional pass, not aesthetic animation approval**. The playback documents its renderer approximations and zero-phase sine assumption where the original source omits phase conventions.

The separately selected static Quest Girl v7 character is unchanged. The motion experiment is a technical library record, not a new gallery exhibit.
